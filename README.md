# Documentation for 3D-kartan and it's backend

The docs are built with mkdocs.

The docs are published here: [3D-kartan Documentation](https://3d-kartan.github.io/3D-kartan-documentation/)

Requirements for developing:

- pip
- mkdocs installed via pip

Local commands:

```sh
mkdocs serve --livereload
mkdocs build
```

Steps to update the docs:

1. Pull the repo
2. Make the changes
3. Push the changes
4. run mkdocs gh-deploy
